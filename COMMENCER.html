Votre premier essai

  1. Extrayez tout le ZIP dans un dossier que vous garderez. Les fichiers dans raw/ sont vos originaux ; wiki/ accueille les fiches.
  2. Double-cliquez sur VERIFIER.cmd. Il liste les outils disponibles sans rien installer ni envoyer.
  3. Lancez INSTALLER.cmd si votre assistant manque. Choisissez 1 pour Claude Code ou 2 pour Codex. Le lanceur demande votre accord avant les installations. Claude est proposé en natif ; Codex via Node.js LTS et npm si nécessaire. Python est réservé aux vidéos.
  4. Ouvrez OUVRIR-CERVEAU.cmd. Choisissez Claude Code (compte Claude) ou Codex (compte ChatGPT avec accès Codex), puis connectez-vous. Lors du premier lancement, vérifiez le dossier autorisé : uniquement votre copie du kit.
  5. Copiez cette demande dans votre assistant :
    Lis raw/exemple-atelier.md. Quel est le délai prévu et qu’est-ce qui reste à confirmer ? Cite le passage source.
  6. Ajoutez votre première note .txt ou .md dans raw/ et demandez de la classer. Relisez la fiche obtenue avant de vous y fier.

Pas de compte compatible ? Vous pouvez lire l’exemple et utiliser les dossiers manuellement. L’assistant ne fonctionnera pas tant que votre assistant n’est pas installé et connecté. Le kit ne remplace pas cet accès.

Vous choisissez quand il travaille

Classer une source

Déposez un fichier, puis demandez : « Classe raw/ma-note.md ». La simple copie du fichier ne lance rien.

Retrouver une information

Posez votre question dans Claude Code ou Codex. Vérifiez la source citée. Si l’information manque, l’assistant doit vous le dire.

Réutiliser votre savoir

Demandez un brief, une checklist ou une comparaison à partir des sources. Vous décidez si cette réponse devient une nouvelle fiche.

Faire le point

Demandez « Fais le bilan de mon cerveau » ou « Vérifie les fiches et leurs sources ». Les raccourcis /digest et /lint sont réservés à Claude Code. Aucun déclenchement automatique.

Les vidéos sont une option

INSTALLER-VIDEOS.cmd propose les dépendances et les installe dans un environnement Python séparé. La transcription est locale, sans appel à votre compte IA. Ajoutez vos URLs dans youtube.md puis lancez TRAITER-VIDEOS.cmd.

Le traitement s’arrête à la fin du lot. Les notes arrivent dans raw/youtube/ ; ouvrez Claude Code ou Codex et demandez de résumer et classer la note en citant ses repères horodatés. Un téléchargement échoué reste en attente pour le prochain lancement.

Le modèle de transcription est téléchargé au premier usage. Le temps et l’espace nécessaires dépendent de votre machine et des vidéos. Limites du kit : pas de direct, deux heures maximum par vidéo, audio téléchargé plafonné à 256 Mo. Utilisez des contenus autorisés. Les restrictions de YouTube peuvent empêcher un téléchargement.

Ce que le kit ne fait pas

Il ne lit pas vos emails, ne se connecte pas à votre CRM, ne surveille pas votre disque et ne gère pas les accès d’une équipe. Les scans et formats bureautiques nécessitent parfois une conversion non incluse. Les réponses IA restent à vérifier.

Vos fichiers et vos coûts

Les notes restent dans ce dossier. Leur contenu peut être transmis à Anthropic avec Claude Code, ou à OpenAI avec Codex : ce n’est pas une IA entièrement locale. B2Labs ne reçoit pas vos documents via le kit. Aucun abonnement ni crédit IA n’est inclus.

Sauvegardez votre dossier. Ne partagez pas votre copie après y avoir ajouté des informations personnelles : partagez le ZIP d’origine. Les scripts sont lisibles et n’installent aucun service en arrière-plan.

Si quelque chose bloque

Relancez VERIFIER.cmd, consultez le guide de dépannage. Si un outil vient d’être installé, fermez les fenêtres et recommencez. Si les scripts sont bloqués par votre entreprise, demandez à votre administrateur ou utilisez les commandes manuelles documentées.

Parcours automatisé : Windows 10/11. Autres plateformes : instructions manuelles dans README.md, non validées dans cette version. Une fenêtre de terminal est normale ; aucun .exe B2Labs opaque n’est nécessaire.
