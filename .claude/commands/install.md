Lis README.fr.md. Explique le choix Claude Code ou Codex : un seul assistant suffit et l’accès appartient à l’utilisateur. Python, FFmpeg et Deno ne servent qu’à l’option vidéo.
Sur Windows, propose VERIFIER.cmd pour le diagnostic, INSTALLER.cmd pour l’assistant et INSTALLER-VIDEOS.cmd uniquement si l’utilisateur veut la transcription. Ne lance pas d’installation sans sa demande. Sur les autres plateformes, oriente vers les documentations officielles et précise que les lanceurs ne sont pas validés.
N’enregistre aucune clé, ne crée pas de chemin personnel dans une configuration partagée, n’initialise pas de dépôt distant et ne fais pas de commit automatique. Ne remplace pas les notes ni les index déjà remplis. Propose l’exemple fictif pour le premier essai ; n’annonce pas une installation réussie sans avoir vérifié le code de sortie.
