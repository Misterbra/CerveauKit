# Cerveau Kit

> 🇫🇷 Version française : [README.fr.md](README.fr.md)

A self-feeding second brain: **Obsidian + Claude Code + automatic YouTube ingestion**.

Drop in your sources — articles, PDFs, YouTube links — and the agent reads them,
transcribes them, summarizes them, cross-links them, and grows your knowledge base
every time you ask it a question. Based on Andrej Karpathy's *"LLM wiki"* pattern,
augmented with a full YouTube pipeline (download, Whisper transcription, summary).

> **Heads up — the tool speaks French.** Slash commands, prompts, and the notes it
> generates are in French (see `CLAUDE.md` and `.claude/commands/`). The code and this
> README are in English. To switch the interface language, translate those two places.

## How it works

```
sources ──▶  raw/        (never modified)
              │
   /ingest    │  /youtube (download → Whisper → summary)
              ▼
            wiki/        ◀── the agent writes & maintains linked pages
              │
   your question ──▶ the agent reads the wiki, cites its sources,
                     and offers to save new insights back as a page (the loop)
```

## Requirements

- **Python 3.11+** ([python.org](https://python.org) — tick *"Add Python to PATH"*)
- **Claude Code** ([claude.com/claude-code](https://claude.com/claude-code)) — required for the
  librarian (wiki, Q&A, ingestion). The YouTube part works without it.
- **Obsidian** (free, optional — [obsidian.md](https://obsidian.md)) to browse your notes.
- **ffmpeg** and **yt-dlp** — the installer checks for them and helps you install them.

## Install — 2 minutes

**With Claude Code (full experience):**

1. Unzip this folder wherever you like (it becomes your brain).
2. Open a terminal in the folder and run `claude`.
3. Type: **`/install`**

**Without Claude Code (Windows, YouTube pipeline only):**

1. Unzip this folder.
2. Double-click **`INSTALLER.bat`** — it installs the dependencies and asks a single
   question (how to summarize: Claude Code, an Anthropic API key, or no summary).
3. Paste your links into `youtube.md`, then double-click **`TRAITER-VIDEOS.bat`**.

**macOS / Linux** — same steps in a terminal:

```sh
pip install -r tools/tubescribe/requirements.txt
python tools/setup.py
cd tools/tubescribe && python -m tubescribe watch
```

Without Claude Code you get: download, Whisper transcription, summary (if an API key is
set) and organized markdown notes — but not the librarian (the auto-linked wiki, the
Q&A loop, `/ingest`).

## Daily use

| Action | How |
|--------|-----|
| Add an article / PDF | Drop the file in `raw/`, then `/ingest` |
| Add a YouTube video | Paste the link into `youtube.md`, then `/youtube` |
| Ask a question | Just ask — the agent reads the wiki and cites its sources |
| Save a good answer | The agent offers to save it back as a new page (the loop) |
| Maintenance | `/lint` (consistency) and `/digest` (periodic recap) now and then |

## Structure

```
raw/        your raw sources (never modified)
wiki/       synthesis pages generated by the agent
youtube.md  watchlist of videos to process
index.md    catalog of every page
log.md      journal of every operation
tools/      TubeScribe, the YouTube pipeline (Python)
```

## TubeScribe — the YouTube pipeline

A standalone Python tool that turns a markdown watchlist of YouTube links into
transcribed, summarized, ready-to-file notes: watchlist → download (yt-dlp) →
transcribe (faster-whisper, GPU or CPU) → summarize (Claude) → one markdown note per
video, then the watchlist line is checked off so nothing is processed twice.
See [`tools/tubescribe/README.md`](tools/tubescribe/README.md) for details.
